# AgroDose

## Project Overview:
The Idea:

AgroDose automates and validates dosage conversions for plant protection products (e.g., $g/ha \leftrightarrow g/hL$), integrates operational equipment parameters (nozzle flow rate, pressure, forward speed), and maintains an immutable historical record of applied treatments (Field Log Book). The system eliminates manual calculation errors during spray preparation and ensures complete traceability of farming operations.
